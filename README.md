One fortune cookie message, at most 20 words, for a crypto trader who has just been liquidated.

> Your next trade will be green. The market has read this cookie and is already laughing.

## How it works

`main.ts` (Node 22, stdlib only, no network, no wall clock) reads the fortune from `entry.txt` in the repo root, checks it is 1–160 characters and at most 20 words, and writes it unchanged to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

## Run

```sh
MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=./output node main.ts
```
